# Roadmap

## Current Beta

Current release:

- `v0.2.0-beta.1`
- codename: `Cherwell`

Current beta status:

- core clipboard server is implemented
- embedded Web UI is implemented
- pairing, favorites, cleanup, and WebDAV manual sync preview are implemented
- project is still beta and focused on polishing rather than large platform expansion

## Near-Term Candidates

Near-term work should stay realistic and incremental:

- continue polishing the Cherwell Web UI
- improve project documentation and deployment examples
- refine bilingual Web UI text and onboarding clarity
- tighten packaging and release quality
- improve manual WebDAV preview reliability and UX

## Future Direction

These are future directions, not completed deliverables:

- lightweight desktop clients built on top of the HTTP API
- lightweight mobile clients built on top of the HTTP API
- better long-term sync UX
- more operational polish for self-hosted users

## Not Claimed As Complete

The project does not currently claim:

- finished desktop clients
- finished mobile clients
- automatic background WebDAV sync
- enterprise-grade auth or session management
